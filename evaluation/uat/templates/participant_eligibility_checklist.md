# Participant eligibility checklist

> **OWNER / SCOUT ACTION REQUIRED — NO USERS RECRUITED YET**

Mark only after a real person is recruited. Leave blank until then.

- [ ] Adult professional with legitimate access to the operational context
- [ ] Not a fabricated or duplicated identity
- [ ] Written consent stored offline and assigned an opaque reference
- [ ] Understands that the system cannot execute actions

- [ ] Can provide or review a reference outcome / escalation decision
